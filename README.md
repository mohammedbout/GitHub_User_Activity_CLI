# Github-User-Activity
This is a program that fetches the user activity on github and displays it on the console.
This project is from the github user activity challenge on https://roadmap.sh/projects/github-user-activity
# How to use
Clone the repository and use the following command:
git clone https://github.com/mohammedbout/GitHub_User_Activity_CLI.git

Run the following command to list the activities of a user:
java GithubActivity MoBT
